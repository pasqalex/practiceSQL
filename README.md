# SQL Practice Tasks

Учебные задачи по SQL, решённые в рамках курса самостоятельной подготовки. Основной стек: PostgreSQL, DBeaver, MySQL. 

## Содержание

| # | Файл | Суть задачи |
|---|------|-------------|
| 1 | `1_practiceSQL` | Курьеры, доставившие 30+ заказов за сентябрь |
| 2 | `2_practiceSQL` | Последние 100 доставленных заказов и их состав |
| 3 | `3_practiceSQL` | Возраст пользователей с заменой NULL на среднюю дату рождения |
| 4 | `4_practiceSQL` | Время принятия/доставки крупных неотменённых заказов без JOIN |

## Используемые техники

- CTE (`WITH`)
- Агрегация с `FILTER`
- `EXISTS` / `NOT EXISTS`
- Подзапросы в `SELECT`
- `DATE_TRUNC`, `AGE`, `EXTRACT`
- `COALESCE`
- `FETCH FIRST` / `OFFSET`

## Примечания

- Задачи взяты из открытых источников.
- Некоторые решения намеренно немного усложнены, чтобы прокачать работу с подзапросами.
- Чуть более интересные задачи описаны в отдельных приложенных файлах.
