# User Order Statistics

**Задача:** для каждого пользователя посчитать статистику по неотменённым заказам: количество заказов, средний размер заказа, суммарную стоимость, средний, минимальный и максимальный чек.

## Логика решения

1. **all_not_canceled_orders**  
   Находим заказы, которые не были отменены.  
   Для каждого `order_id` проверяем, что в `user_actions` нет записи с действием `cancel_order`.  
   Сохраняем `user_id`, чтобы привязать заказ к пользователю.

2. **expand_orders**  
   Разворачиваем массивы товаров (`product_ids`) в строки и присоединяем к ним `user_id` из неотменённых заказов.

3. **order_prices**  
   Для каждого заказа считаем его полную стоимость: суммируем цены всех товаров внутри заказа.

4. **order_stats**  
   Группируем заказы по пользователям и считаем:
   - количество заказов;
   - сумму всех заказов;
   - средний чек;
   - минимальный и максимальный чек.

5. **product_stats**  
   Для каждого пользователя считаем общее количество купленных товаров.

6. **Финальный запрос**  
   Объединяем статистику по заказам и товарам.  
   Добавляем средний размер заказа как отношение числа товаров к числу заказов.

## Использованные методы

- **CTE (`WITH`)** - пошаговая декомпозиция задачи.
- **`NOT EXISTS`** - исключение отменённых заказов.
- **`UNNEST`** - разворачивание массива товаров в строки.
- **`LEFT JOIN`** - подтягивание цен товаров.
- **`SUM()` / `AVG()` / `MIN()` / `MAX()`** - агрегация по заказам и пользователям.
- **`GROUP BY`** - расчёт метрик на уровне заказа и пользователя.
- **`ROUND` + приведение к `DECIMAL`** - аккуратное округление средних значений.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `user_id` | Идентификатор пользователя |
| `orders_count` | Количество неотменённых заказов |
| `avg_order_size` | Среднее количество товаров в заказе |
| `sum_order_value` | Суммарная стоимость всех заказов |
| `avg_order_value` | Средний чек |
| `min_order_value` | Минимальный чек |
| `max_order_value` | Максимальный чек |

## Вывод

Запрос даёт полную картину покупательского поведения по каждому пользователю: как часто заказывает, на какую сумму, насколько крупные заказы. Это полезно для сегментации клиентов, оценки среднего чека и анализа удержания.
