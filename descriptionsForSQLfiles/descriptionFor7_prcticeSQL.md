# Orders Containing Top Expensive Products

**Задача:** найти все заказы, в состав которых входит хотя бы один товар из топ-5 самых дорогих товаров.

## Логика решения

1. **top_expensive_products**  
   Выбираем топ-5 самых дорогих товаров по цене.

2. **expanded_orders**  
   Разворачиваем массивы товаров (`product_ids`) в отдельные строки, чтобы можно было сравнивать каждый товар заказа с товарами из топа.

3. **orders_with_expensive_products**  
   Оставляем только те заказы, в которых есть хотя бы один товар из топ-5 дорогих.

4. **Финальный запрос**  
   Выводим исходные заказы с их полным составом товаров.  
   Сортируем по `order_id`.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи на логические этапы.
- **`UNNEST`** - разворачивание массива товаров в строки.
- **`EXISTS`** - проверка наличия товара из заказа в списке топ-5 дорогих.
- **`ORDER BY ... DESC` + `LIMIT`** - выбор самых дорогих товаров.
- **Связь через `EXISTS`** - возврат исходных заказов без дублирования строк.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `order_id` | Идентификатор заказа |
| `product_ids` | Массив идентификаторов товаров в заказе |

## Вывод

Запрос позволяет выделить заказы, содержащие премиальные товары. Это полезно для анализа покупательского поведения, сегментации клиентов и планирования маркетинговых акций, связанных с дорогими позициями.

# Orders Containing Top Expensive Products (Optimized)

**Задача:** найти все заказы, в состав которых входит хотя бы один товар из топ-5 самых дорогих товаров.

## Логика решения

1. **top_expensive_products**  
   Выбираем топ-5 самых дорогих товаров по цене.

2. **Финальный запрос**  
   Для каждого заказа проверяем, есть ли в его массиве товаров хотя бы один из топ-5 дорогих.  
   Если есть - выводим заказ с полным составом товаров.

## Использованные методы

- **CTE (`WITH`)** - изоляция списка дорогих товаров.
- **`ANY`** - проверка вхождения элементов массива в список топ-5 без разворачивания массива.
- **`EXISTS`** - проверка наличия совпадений между товарами заказа и дорогими товарами.
- **`ORDER BY ... DESC` + `LIMIT`** - выбор самых дорогих товаров.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `order_id` | Идентификатор заказа |
| `product_ids` | Массив идентификаторов товаров в заказе |

## Вывод

Запрос позволяет быстро и без лишней работы с массивами находить заказы с дорогими товарами. Это эффективнее версии с `UNNEST`, так как не разворачивает массивы в строки, а проверяет условие на уровне одной строки.
