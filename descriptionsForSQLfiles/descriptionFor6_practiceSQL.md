# Top Products in Non-Canceled Orders

**Задача:** определить топ-10 самых часто покупаемых товаров среди заказов, которые не были отменены.

## Логика решения

Запрос разбит на несколько шагов:

1. **all_canceled_orders**  
   Находим все `order_id`, которые были отменены (`action = 'cancel_order'`).

2. **all_not_canceled_orders**  
   Отбираем только неотменённые заказы.  
   Оставляем только `order_id`, которых нет в списке отменённых.

3. **top_purchases**  
   Разворачиваем массивы товаров (`product_ids`) из заказов в отдельные строки.  
   Считаем, сколько раз каждый товар встречался в неотменённых заказах.  
   Оставляем топ-10 по убыванию популярности.

4. **Финальный запрос**  
   Выводим результат, отсортированный по `product_id`.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи на логические этапы.
- **`EXISTS` / `NOT EXISTS`** - фильтрация заказов по наличию в списке отменённых.
- **`UNNEST`** - разворачивание массива `product_ids` в строки.
- **`COUNT()` + `GROUP BY`** - подсчёт частоты покупок каждого товара.
- **`ORDER BY ... DESC` + `LIMIT`** - выбор топ-10 самых популярных товаров.
- **`MATERIALIZED`** - явная материализация промежуточного результата для гарантии порядка и отсечения лишних строк.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `times_purchased` | Сколько раз товар встречался в неотменённых заказах |
| `product_id` | Идентификатор товара |

## Вывод

Запрос позволяет определить самые востребованные товары среди успешных заказов. Это полезно для анализа ассортимента, планирования закупок и оценки реального спроса без учёта отменённых покупок.
