# Last 100 Delivered Orders and Their Products

**Задача:** получить список из последних 100 доставленных заказов и состав товаров в них.

## Логика решения

1. **deliver**  
   Находим последние 100 заказов, которые были доставлены (`action = 'deliver_order'`).  
   Сортируем по времени доставки от новых к старым и берём первые 100 строк.

2. **Финальный запрос**  
   Достаём из таблицы `orders` состав товаров (`product_ids`) для этих заказов.  
   Сортируем по `order_id`.

## Использованные методы

- **CTE (`WITH`)** — выделение последних доставленных заказов в отдельный блок.
- **`ORDER BY ... DESC` + `FETCH FIRST`** — отбор 100 последних записей.
- **`IN` + подзапрос** — фильтрация товарных составов по списку заказов.
- **Диапазонная работа с датами** — использование времени доставки для сортировки.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `order_id` | Идентификатор заказа |
| `product_ids` | Массив идентификаторов товаров в заказе |

## Вывод

Запрос помогает быстро получить составы последних выполненных заказов. Это удобно для контроля последних операций, сверки с курьерами и анализа ассортимента в свежих доставках.
