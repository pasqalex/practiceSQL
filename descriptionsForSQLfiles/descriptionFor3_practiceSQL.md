# User Age with Missing Birth Date Replacement

**Задача:** посчитать возраст пользователей, заменив пропущенные даты рождения на среднюю дату рождения по всем пользователям.

## Логика решения

Запрос разбит на несколько этапов:

1. **CalcAge**  
   Находим максимальную дату (`MAX(time)`) из таблицы `user_actions`.  
   Она используется как точка отсчёта для расчёта возраста.

2. **avgAge**  
   Вычисляем среднюю дату рождения по всем пользователям.  
   Она понадобится для замены `NULL` в колонке `birth_date`.

3. **Финальный запрос**  
   Для каждого пользователя считаем возраст с помощью `AGE`.  
   Если дата рождения не указана — подставляем среднюю дату через `COALESCE`.  
   Из результата извлекаем только годы.

## Использованные методы

- **CTE (`WITH`)** — выделение логических шагов.
- **`EXTRACT(EPOCH ...)`** — преобразование даты в число для усреднения.
- **`TO_TIMESTAMP`** — обратное преобразование среднего значения в дату.
- **`AVG()` + `CAST`** — расчёт средней даты рождения.
- **`COALESCE`** — замена `NULL` запасным значением.
- **`AGE`** — расчёт интервала между датами.
- **`EXTRACT(YEAR ...)`** — извлечение количества лет из интервала.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `user_id` | Идентификатор пользователя |
| `age` | Возраст пользователя в годах на основе максимальной даты активности |
