**Что делает:** разворачивает месяцы из строк в колонки.

## Метод

Используется `SUM(IF(month = '...', revenue, NULL))`.

Для каждого месяца проверяется условие: если строка относится к нужному месяцу — берём `revenue`, иначе `NULL`.  
Потом `SUM` складывает только подходящие значения.

Это стандартный способ пивота без `PIVOT`.

## Результат

| Колонка | Описание |
|:---|:---|
| `id` | ID отдела |
| `Jan_Revenue` ... `Dec_Revenue` | Выручка по месяцам |
