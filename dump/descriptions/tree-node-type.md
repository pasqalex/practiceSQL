# Tree Node Type

**Что делает:** определяет, чем является каждый узел дерева — корнем, внутренним узлом или листом.

## Логика

- `p_id IS NULL` → `Root`
- есть потомки → `Inner`
- нет потомков → `Leaf`

Потомки проверяются через `EXISTS`: смотрим, ссылается ли кто-то на текущий `id` как на родителя.

## Результат

| Колонка | Описание |
|:---|:---|
| `id` | ID узла |
| `type` | `Root`, `Inner` или `Leaf` |
