# First Purchase Analysis

**Задача:** посчитать количество **первых** неотменённых заказов пользователей по дням.

## Логика решения

Решение разбито на несколько этапов:

1. **all_canceled_orders**  
   Находим все `order_id`, которые были отменены (`action = 'cancel_order'`).

2. **all_not_canceled_orders**  
   Отбираем только неотменённые заказы.  
   Для каждой строки оставляем `user_id` и дату заказа.

3. **find_minimal_date_of_purchase**  
   Для каждого `user_id` находим минимальную дату покупки — это и есть **первая покупка**.

4. **Финальный запрос**  
   Считаем, сколько пользователей совершили первую покупку в каждую дату.  
   Группируем по `first_date_of_purchase` и сортируем по дате.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `first_orders` | Количество пользователей, совершивших первую покупку в этот день |
| `date` | Дата первой покупки |

## Вывод

Запрос позволяет понять, в какие даты пользователи чаще всего совершают **первую покупку**. Это полезно для анализа поведения новых пользователей и эффективности маркетинговых кампаний.
