# Couriers with some of Experience

**Задача:** отобрать курьеров, которые работают 10 и более дней, и посчитать количество доставленных ими заказов.

**SQL-файл:** [`couriers_with_some_experience.sql`](../sql/couriers_with_some_experience.sql)

## Логика решения

1. **canceled_orders**  
   Находим все отменённые заказы.

2. **not_canceled_orders**  
   Оставляем только неотменённые заказы.

3. **courier_stats**  
   Для каждого курьера считаем:
   - количество принятых неотменённых заказов;
   - количество отработанных дней от первого принятого заказа до последнего времени в таблице.

4. **Финальный запрос**  
   Оставляем только курьеров с опытом от 10 дней.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи.
- **`NOT EXISTS`** - исключение отменённых заказов.
- **`MIN` / `MAX`** - поиск первого и последнего действия.
- **`AGE`** - расчёт интервала между датами.
- **`EXTRACT(DAY ...)`** - извлечение количества дней.
- **`CEIL`** - округление вверх до целого дня.
- **`COUNT` + `GROUP BY`** - подсчёт заказов по курьерам.

## Проверка конкретного курьера

Для отладки используется отдельный запрос по `courier_id = 42`.  
Он выводит:

- `raw_age` - сырой интервал между первым и последним действием;
- `day_part` - количество целых дней, которое даёт `EXTRACT(DAY ...)`;
- `days_float` - точное количество дней с дробной частью.

Это помогает проверять пограничные случаи, когда стаж курьера находится около 10 дней.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `courier_id` | Идентификатор курьера |
| `delivered_orders` | Количество доставленных заказов |
| `days_employed` | Количество отработанных дней |

## Вывод

Запрос позволяет выделить опытных курьеров и оценить их загруженность. Это полезно для анализа удержания персонала и планирования смен.
