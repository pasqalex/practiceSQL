# Top Couriers by September Deliveries

**Задача:** найти курьеров, доставивших 30 и более заказов за сентябрь 2022 года, и вывести их данные.

**SQL-файл:** [`top_couriers_by_september_deliveries.sql`](../sql/top_couriers_by_september_deliveries.sql)

## Логика решения

1. **best**  
   Для каждого курьера считаем количество доставленных заказов (`action = 'deliver_order'`) за сентябрь.  
   Оставляем только тех, у кого доставок 30 и более.

2. **Финальный запрос**  
   Выводим данные курьеров из таблицы `couriers`, которые попали в список `best`.  
   Сортируем по `courier_id`.

## Использованные методы

- **CTE (`WITH`)** - изоляция логики подсчёта доставок.
- **Агрегация с `FILTER`** - подсчёт только доставленных заказов.
- **`HAVING`** - фильтрация курьеров по количеству доставок.
- **`IN` + подзапрос** - выбор курьеров из заранее отобранного списка.
- **Фильтр по диапазону дат** - отбор заказов строго за сентябрь.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `courier_id` | Идентификатор курьера |
| `birth_date` | Дата рождения курьера |
| `sex` | Пол курьера |

## Вывод

Запрос позволяет выделить самых результативных курьеров за сентябрь. Это полезно для оценки нагрузки, мотивации персонала и анализа эффективности доставки.
