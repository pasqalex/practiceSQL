# Top 10% Couriers by Non-Canceled Deliveries

**Задача:** определить топ-10% курьеров по количеству доставленных неотменённых заказов.

**SQL-файл:** [`top_10_percent_couriers_by_deliveries.sql`](../sql/top_10_percent_couriers_by_deliveries.sql)

## Логика решения

1. **canceled_orders**  
   Находим все уникальные отменённые заказы.  
   Защита: `DISTINCT` убирает дубли, `order_id IS NOT NULL` отсекает пустые значения.

2. **valid_deliveries**  
   Оставляем только доставленные заказы, которые не были отменены.  
   Защита: проверка `courier_id IS NOT NULL`, `order_id IS NOT NULL` и `NOT EXISTS` против отменённых заказов.

3. **courier_stats**  
   Для каждого курьера считаем количество доставленных неотменённых заказов.  
   Защита: `COUNT(DISTINCT order_id)` не даёт дублям завысить метрику.

4. **all_couriers**  
   Считаем общее количество уникальных курьеров.  
   Защита: отфильтрован `courier_id IS NOT NULL`.

5. **ranked**  
   Ранжируем курьеров по количеству доставок.  
   Защита: при равенстве числа заказов сортировка по `courier_id` делает порядок стабильным.

6. **limit_calc**  
   Вычисляем, сколько курьеров входят в топ-10%.  
   Защита: `CEIL` округляет вверх, а `GREATEST(1, ...)` гарантирует, что лимит не станет нулём.

7. **Финальный запрос**  
   Выводим курьеров, попавших в топ-10%.

## Использованные методы

- **CTE (`WITH`)** — декомпозиция задачи на слои.
- **`DISTINCT`** — исключение дублей.
- **`NOT EXISTS`** — отсев отменённых заказов.
- **`COUNT(DISTINCT ...)`** — корректный подсчёт уникальных заказов.
- **`ROW_NUMBER`** — ранжирование курьеров.
- **`CEIL`** — округление вверх для расчёта 10%.
- **`GREATEST`** — защита от нулевого лимита.
- **`CROSS JOIN`** — подстановка одного лимита ко всем строкам.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `courier_id` | Идентификатор курьера |
| `orders_count` | Количество доставленных неотменённых заказов |
| `courier_rank` | Место курьера в общем рейтинге |

## Вывод

Запрос позволяет выделить наиболее эффективных курьеров. Это полезно для мотивации персонала, анализа качества доставки и управления нагрузкой.
