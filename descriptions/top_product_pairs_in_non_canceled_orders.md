# Most Frequent Product Pairs in Non-Canceled Orders

**Задача:** найти самые частые пары товаров в неотменённых заказах, где количество товаров больше одного.

**SQL-файл:** [`top_product_pairs_in_non_canceled_orders.sql`](../sql/top_product_pairs_in_non_canceled_orders.sql)

## Логика решения

1. **all_not_canceled_orders**  
   Определяем заказы, которые не были отменены.  
   Используем `LEFT JOIN` + `IS NULL`, чтобы оставить только неотменённые.

2. **filtered_orders_with_more_than_1_products**  
   Оставляем только те заказы, в которых больше одного товара.

3. **expand_orders**  
   Разворачиваем массивы товаров (`product_ids`) в отдельные строки.

4. **rename_values**  
   Подтягиваем названия товаров вместо идентификаторов.

5. **Финальный запрос**  
   С помощью `CROSS JOIN` строим все возможные пары товаров внутри одного заказа.  
   Убираем симметричные дубли через `rv1.name < rv2.name`.  
   Считаем количество заказов для каждой пары.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи на логические слои.
- **`LEFT JOIN` + `IS NULL`** - фильтрация неотменённых заказов.
- **`ARRAY_LENGTH`** - определение количества товаров в заказе.
- **`UNNEST`** - разворачивание массива товаров в строки.
- **`CROSS JOIN`** - построение всех возможных пар внутри заказа.
- **`ARRAY[...]`** - формирование пары в виде массива.
- **`COUNT(DISTINCT ...)`** - подсчёт уникальных заказов для каждой пары.
- **`ORDER BY`** - сортировка по популярности пары.

## Почему `rv1.name < rv2.name`

Чтобы исключить дубли вида `['хлеб', 'курица']` и `['курица', 'хлеб']`, оставляется только одна комбинация - та, где название первого товара лексикографически меньше второго.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `pair` | Пара товаров в виде массива |
| `count_pair` | Количество заказов с такой парой |

## Вывод

Запрос позволяет выявить устойчивые сочетания товаров, которые пользователи чаще всего покупают вместе.

Это можно использовать для:

- **Перекрёстных продаж** - если покупатель берёт «курицу», предложить ему «хлеб».
- **Управления ассортиментом** - товары из частых пар размещать рядом на витрине.
- **Маркетинговых акций** - делать скидки на сопутствующие товары.
- **Планирования закупок** - понимать, какие товары нужно держать на складе одновременно.

Такие данные помогают увеличивать средний чек и удерживать клиентов за счёт удобных предложений.
