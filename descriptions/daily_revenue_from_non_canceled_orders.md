# Daily Revenue from Non-Canceled Orders

**Задача:** посчитать ежедневную выручку по неотменённым заказам.

**SQL-файл:** [`daily_revenue_from_non_canceled_orders.sql`](../sql/daily_revenue_from_non_canceled_orders.sql)

## Логика решения

1. **all_not_canceled_orders**  
   Находим заказы, которые не были отменены.  
   Для каждого `order_id` проверяем, что в `user_actions` нет записи с действием `cancel_order`.  
   Сохраняем `time`, чтобы позже определить дату заказа.

2. **expand_orders**  
   Присоединяем к неотменённым заказам состав товаров.  
   Разворачиваем массивы `product_ids` в строки.

3. **order_prices**  
   Для каждого заказа считаем его полную стоимость.  
   Приводим `time` к дате, чтобы получить день заказа.

4. **Финальный запрос**  
   Суммируем стоимости заказов по дням.  
   Получаем выручку за каждую дату.

## Использованные методы

- **CTE (`WITH`)** - пошаговая декомпозиция задачи.
- **`NOT EXISTS`** - исключение отменённых заказов.
- **`UNNEST`** - разворачивание массива товаров в строки.
- **`LEFT JOIN`** - подтягивание цен товаров.
- **`CAST(time AS DATE)`** - приведение времени к дате для группировки по дням.
- **`SUM()` + `GROUP BY`** - расчёт стоимости заказа и итоговой выручки.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `date` | Дата заказа |
| `revenue` | Выручка за день по неотменённым заказам |

## Вывод

Запрос позволяет отслеживать ежедневную выручку без учёта отменённых заказов. Это полезно для анализа динамики продаж, оценки эффективности маркетинговых акций и контроля финансовых показателей.
