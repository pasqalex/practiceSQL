# Average Hours Between Non-Canceled Orders

**SQL-файл:** [`avg_hours_between_orders.sql`](../sql/avg_hours_between_orders.sql)

**Задача:** для каждого пользователя посчитать среднее количество часов между его неотменёнными заказами.

## Логика решения

1. **canceled_orders**  
   Находим все отменённые заказы.

2. **all_not_canceled_orders**  
   Оставляем только неотменённые заказы.  
   С помощью оконной функции `COUNT ... OVER` считаем общее количество заказов у каждого пользователя.

3. **some_values**  
   Отбираем только пользователей, у которых больше одного заказа.  
   Через `LAG` получаем время предыдущего заказа.

4. **Финальный запрос**  
   Для каждого пользователя считаем среднюю разницу между заказами в часах.

## Использованные методы

- **CTE (`WITH`)** — пошаговая декомпозиция задачи.
- **`NOT EXISTS`** — исключение отменённых заказов.
- **Оконные функции** — `COUNT ... OVER` и `LAG ... OVER`.
- **`PARTITION BY`** — расчёт метрик внутри каждого пользователя.
- **`EXTRACT(EPOCH ...)`** — перевод интервала в секунды.
- **Деление на 3600** — перевод секунд в часы.
- **`ROUND` + `CAST`** — приведение к целому числу часов.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `user_id` | Идентификатор пользователя |
| `hours_between_orders` | Среднее количество часов между заказами |

## Вывод

Запрос помогает понять, с какой периодичностью пользователи делают повторные заказы. Это полезно для анализа удержания, планирования маркетинговых коммуникаций и оценки лояльности клиентов.
