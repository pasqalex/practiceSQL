# Couriers Above Average Deliveries

**Задача:** для каждого курьера сравнить количество доставленных заказов со средним значением по всем курьерам.

**SQL-файл:** [`couriers_above_avg_deliveries.sql`](../sql/couriers_above_avg_deliveries.sql)

## Логика решения

1. **canceled_orders**  
   Находим все отменённые заказы.

2. **all_not_canceled_orders**  
   Оставляем только неотменённые заказы, доставленные в сентябре 2022 года.  
   Подтягиваем `courier_id` через `JOIN` с `courier_actions`.

3. **some_values**  
   Для каждого курьера считаем количество доставленных заказов.

4. **Финальный запрос**  
   Сравниваем количество доставок курьера со средним значением по всем курьерам.  
   Используем оконную функцию `AVG ... OVER()`.

## Использованные методы

- **CTE (`WITH`)** — декомпозиция задачи на логические слои.
- **`NOT EXISTS`** — исключение отменённых заказов.
- **`JOIN`** — связывание заказов с курьерами.
- **`COUNT ... GROUP BY`** — подсчёт доставок по курьерам.
- **Оконная функция `AVG ... OVER()`** — расчёт общего среднего значения.
- **`CASE`** — классификация курьеров относительно среднего.
- **`ROUND`** — округление среднего значения.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `courier_id` | Идентификатор курьера |
| `delivered_orders` | Количество доставленных заказов |
| `is_above_avg` | Выше среднего (`1`), ниже (`0`) или равен (`окак`) |
| `avg_delivered_orders` | Среднее количество доставок по всем курьерам |

## Вывод

Запрос позволяет быстро выявить курьеров с аномальной нагрузкой. Это полезно для оценки производительности курьеров и планирования распределения заказов.
