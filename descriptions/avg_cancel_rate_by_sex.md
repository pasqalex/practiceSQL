# Average Cancel Rate by Sex

**Задача:** посчитать средний процент отменённых заказов среди пользователей в разрезе пола.

**SQL-файл:** [`avg_cancel_rate_by_sex.sql`](../sql/avg_cancel_rate_by_sex.sql)

## Логика решения

1. **all_canceled_orders**  
   Находим все отменённые заказы.  
   Используем `MATERIALIZED`, чтобы список отменённых заказов посчитался один раз.

2. **count_of_orders**  
   Для каждого пользователя считаем:
   - количество отменённых заказов - через `EXISTS`;
   - количество неотменённых заказов - через `NOT EXISTS`.

3. **user_cancel_rate**  
   Для каждого пользователя считаем индивидуальный `cancel_rate`: отменённые заказы делим на общее число заказов.  
   Значение округляем до двух знаков.

4. **Финальный запрос**  
   Соединяем с таблицей `users`, подтягивая пол.  
   Считаем среднее значение `cancel_rate` по каждому полу.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи на логические этапы.
- **`MATERIALIZED`** - материализация списка отменённых заказов.
- **`COUNT(DISTINCT ...)` + `FILTER`** - аккуратный подсчёт без дублей.
- **`EXISTS` / `NOT EXISTS`** - проверка наличия заказа в списке отменённых.
- **`CAST(... AS DECIMAL)`** - приведение к дробному типу перед делением.
- **`NULLIF`** - защита от деления на ноль.
- **`ROUND`** - округление до нужной точности.
- **`LEFT JOIN`** - подтягивание пола пользователя.
- **`COALESCE`** - замена `NULL` на `unknown`.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `sex` | Пол пользователя |
| `avg_cancel_rate` | Средний процент отменённых заказов по полу |

## Вывод

Запрос позволяет сравнить, как часто отменяют заказы мужчины и женщины. Это полезно для анализа пользовательского поведения, оценки качества заказов и выявления групп риска.
