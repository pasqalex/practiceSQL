# Delivery Time for Large Non-Canceled Orders

**Задача:** для крупных неотменённых заказов найти время принятия заказа курьером, время доставки и длительность доставки.

**SQL-файл:** [`delivery_time_for_large_non_canceled_orders.sql`](../sql/delivery_time_for_large_non_canceled_orders.sql)

## Логика решения

Запрос разбит на несколько этапов:

1. **large_orders**  
   Отбираем заказы, в которых больше пяти товаров (`array_length(product_ids, 1) > 5`).

2. **not_cancelled**  
   Оставляем только те крупные заказы, по которым в `user_actions` нет действия `cancel_order`.

3. **accept_times**  
   Находим время, когда курьер принял каждый из отобранных заказов (`action = 'accept_order'`).

4. **Финальный запрос**  
   Для каждого заказа извлекаем время принятия и время доставки.  
   Через `AGE` считаем, сколько времени прошло между принятием и доставкой.

## Использованные методы

- **CTE (`WITH`)** - декомпозиция задачи на логические слои.
- **`ARRAY_LENGTH`** - определение количества товаров в заказе.
- **`EXISTS`** - фильтрация заказов по связанным действиям в других таблицах.
- **Подзапросы в `SELECT`** - извлечение точечных значений времени доставки.
- **`AGE`** - расчёт длительности между принятием и доставкой.
- **`ORDER BY`** - сортировка результата по номеру заказа.

## Что показывает результат

| Колонка | Описание |
|:---|:---|
| `order_id` | Идентификатор крупного неотменённого заказа |
| `accept_time` | Время принятия заказа курьером |
| `deliver_time` | Время доставки заказа |
| `delivery_duration` | Длительность доставки |

## Вывод

Запрос позволяет проанализировать, сколько времени занимает доставка крупных заказов, которые не были отменены. Это полезно для оценки эффективности курьерской службы и выявления узких мест в логистике.
